🖥️ Tenant Cluster Visibility - Ops UI Wireframe

Overview

This wireframe shows how tenant cluster information will be displayed in the admin ops UI. Workshops are assigned to tenant clusters from TenantClusterPools, and this feature makes that assignment visible to operators.

Technical Details

Data Flow

  1. Workshop has ResourceClaims
  2. ResourceClaim.status.resourceHandle.name → points to TenantClusterPool
  3. TenantClusterPool.status.clusters[] → lists cluster assignments
  4. Match by resourceClaimName to find cluster assignment
